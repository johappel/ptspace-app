1. `REFACTOR-UX.md`
2. `docs/design/DENKRAUM-DESIGN-CONTRACT.md`
3. `docs/design/REFERENCE-STATES.md`
4. `docs/design/FRONTEND-REVIEW-CHECKLIST.md`
5. das aktuelle GitHub-Issue

## Kernfrage

Nicht nur: Funktioniert die neue Oberfläche?

Sondern:

> Unterstützt sie einen ruhigen gemeinsamen pädagogischen Denkprozess, oder verwandelt sie den Planungsraum in ein Dashboard?

Bei Unsicherheit ist die dashboardärmere, gesprächszentriertere und visuell ruhigere Lösung zu bevorzugen, sofern dadurch keine fachliche Information oder Zugänglichkeit verloren geht.
